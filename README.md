# YTBotTelegram
Телеграм-бот для скачивания видео из YouTube, Instagram, ВКонтакте, TikTok. Скачивание происходит асинхронно при отправке ссылка на материал, есть возможность выбора видео/аудио формата, а также разрешения видео. При скачивании какого-либо видео его метаданные сохраняются, следующий пользователь не будет ждать загрузки видео ботом
